Read(about.md) 소개

글로벌 10개국 이상에 서비스하는 자사 이커머스의 회원 도메인을 담당하는 3년차 Java/Spring 백엔드 개발자입니다. 몰/백오피스의 회원 기능 개발부터 대량 데이터 이관, 개인정보 처리 자동화, 레거시 장애 개선까지 수행하고 있습니다.

사업 구조 전환을 위한 배치 3종을 단독 개발하며 10만 건 이상 규모의 회원 이관 시간을 24시간 이상에서 5시간 이내로, 탈퇴 처리 시간을 10시간 이상에서 3시간 30분으로 단축했습니다. 수작업으로 진행하던 탈퇴회원 개인정보 분리보관을 자동화하고, ISMS 인증 대응 과정에서 개인정보 포함 파일의 접근 권한을 비공개로 전환했습니다.

Claude Code, Codex를 활용한 개발 경험도 보유하고 있습니다. 운영 사이트의 드래그앤드롭 기능과 브랜드 히스토리 페이지를 구현하여 테스트 후 배포했으며, 기존 상품/다국어 API와 연동되는 Next.js 기반 메인/상품 상세 페이지 전환 POC를 1주 이내 구현했습니다. Jira 하위 티켓 생성과 Confluence 문서 작성을 자동화하는 Skill을 제작하여 POC에 적용했습니다.

7년 반의 IT 고객센터 경력으로 운영 현장의 언어를 이해하며 요구사항을 구체화하고, 성능 개선과 운영 자동화로 연결하는 것이 강점입니다.

  • 레거시 개선: 리소스 반환 누락, S3 중복 접근 수정
  • Claude Code/Codex 활용: 운영 기능 배포, Next.js POC 구현
